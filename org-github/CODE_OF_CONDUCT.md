# Code of Conduct

This project follows the **[Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/)**. Please read it; it applies to all spaces of the project (issues, pull requests, discussions and any place where you represent it).

In short: be respectful, be welcoming to newcomers, give and accept feedback kindly, and assume good faith. Harassment, personal attacks and discrimination are not tolerated.

## Reporting

To report behaviour that breaks this code, use the **private reporting** option on any repository's Security tab and mark the report as a conduct issue, or contact the organisation owners through GitHub. Reports are handled privately and in good faith.
