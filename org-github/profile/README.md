# SethuCMS

**One CMS for every database.** A security-first admin and content layer that connects to many databases through one adapter contract.

| Repository | What it is |
|---|---|
| [sethucms](https://github.com/sethucms/sethucms) | The gateway (HTTP API) and the core rules |
| [sethucms-admin](https://github.com/sethucms/sethucms-admin) | The admin app |
| [sethucms-adapter-sdk](https://github.com/sethucms/sethucms-adapter-sdk) | The adapter contract and the conformance tests |
| [sethucms-adapters](https://github.com/sethucms/sethucms-adapters) | First-party adapters (memory, PostgreSQL) |
| [sethucms-sdk-ts](https://github.com/sethucms/sethucms-sdk-ts), [-python](https://github.com/sethucms/sethucms-sdk-python), [-dart](https://github.com/sethucms/sethucms-sdk-dart) | Client SDKs |
| [sethucms-adapter-template-python](https://github.com/sethucms/sethucms-adapter-template-python), [-go](https://github.com/sethucms/sethucms-adapter-template-go) | Start a new adapter in Python or Go |
| [sethucms-infra](https://github.com/sethucms/sethucms-infra) | Docker, Kubernetes and Terraform |
| [sethucms-docs](https://github.com/sethucms/sethucms-docs) | Design and build documentation |

New here? Read the [contributing guide](https://github.com/sethucms/.github/blob/main/CONTRIBUTING.md). The most wanted contribution is **a new database adapter**.
