Your content.
Your database.

Connect a database, choose which tables become content, and give your team a clean place to edit, review and publish. Your website or app reads the result through one steady API, whichever database sits underneath.

How it works

Three steps, on your own machine.

There is nothing to sign up for. The gateway is a program you run. The admin panel is a web page that talks to it.

  1. Run the gateway

    Start it next to your database, on your computer or a server. The first start prints a one-time admin token.

  2. Connect your database

    Open the admin, add a connection, and start read-only. Choose which tables to expose as content.

  3. Add your team

    Invite teammates by e-mail with a role. They sign in with Google or GitHub, or an authenticator code on your own server. Then revoke the first token.

cd sethucms
sh scripts/build-all.sh
sh scripts/run-local.sh   # http://127.0.0.1:8080
What’s new

More ways to work with your content.

Recent additions. Each one is covered by tests; the hosted pieces are still being tried on a real deployment.

Projects

One person can have several projects, each with its own connections, people and content, and switch between them from the sidebar. Invite teammates by e-mail.

Schema as code

Describe fields, labels, editors and which fields to hide in a file that lives with your code. It can tighten rules; it never loosens what your database enforces.

Files and images

Upload files with type checks, content sniffing, metadata stripping and storage limits. Files stay private unless you publish them.

Google and GitHub sign-in

Teammates sign in with an account they already have. Roles still decide what each person can do.

Choose the fields you see

Show or hide fields while editing, and switch any field to edit as raw code when you need to.

Smaller, clearer code

Every source file stays under 700 lines, so the project is easier to read, review and trust.

Packages

Install only what you need.

SethuCMS is published as small packages on npm, a free library of JavaScript code. Pick the ones for your job and install them with one command. You can browse all of them on the SethuCMS npm page.

Use SethuCMS in your app

Read and write content from your website or app.

@sethucms/sdk

The TypeScript client for the SethuCMS API. Works in Node 20 or newer, browsers and edge runtimes.

npm install @sethucms/sdk

Connect a database

Install the one that matches the database you already run.

@sethucms/adapter-postgres

PostgreSQL.

npm install @sethucms/adapter-postgres

@sethucms/adapter-mysql

MySQL and MariaDB.

npm install @sethucms/adapter-mysql

@sethucms/adapter-mongodb

MongoDB.

npm install @sethucms/adapter-mongodb

@sethucms/adapter-sqlite

SQLite, using the SQLite built into Node.js.

npm install @sethucms/adapter-sqlite

@sethucms/adapter-firestore

Firestore (Firebase).

npm install @sethucms/adapter-firestore

Build your own

For people who write adapters or tools on top of SethuCMS.

@sethucms/core

Shared types: content model, query language, permissions and errors.

npm install @sethucms/core

@sethucms/adapter-sdk

The adapter contract, a safety layer, and a test suite to check a new adapter.

npm install @sethucms/adapter-sdk

@sethucms/adapter-memory

An in-memory adapter for tests, demos and as a starting template.

npm install @sethucms/adapter-memory

@sethucms/adapter-sql-kit

Shared building blocks for the PostgreSQL, MySQL and SQLite adapters.

npm install @sethucms/adapter-sql-kit
Security first

Built so the safe way is the default.

One login per person

Sign in with Google or GitHub, or with an authenticator code on your own server. No shared password.

Roles that mean something

Admins manage connections and people. Editors work on content. Viewers read published content only.

Read-only first

A new connection starts read-only. New tables stay out of the API until someone reviews them.

A record of every change

An audit log shows who changed what and when, and it is built so tampering shows.

Hashed tokens

API tokens are stored only as hashes and are shown once. Replace one and the old one keeps working for an hour.

You hold the keys

The gateway runs on your side. Your database passwords stay encrypted on your own server.
